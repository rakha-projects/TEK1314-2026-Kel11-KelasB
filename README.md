# TEK1314-2026-Kel11-KelasB
Kelompok 11 Siber Security TEK61-B

## Skenario Proyek

Proyek ini mensimulasikan skenario serangan **web server** pada jaringan berskala kecil dengan tiga entitas utama:
- **Attacker Node** — Kali Linux, berperan sebagai penyerang.
- **Target Node (Korban)** — Ubuntu Server dengan web app rentan, berperan sebagai server yang menjadi sasaran.
- **Monitoring Node** — Security Onion, memantau seluruh segmen jaringan kelompok untuk mendeteksi aktivitas mencurigakan.

Detail topologi jaringan dan skema IP tersedia di folder [`docs/design/`](docs/design/) (`topology.png` dan `ip_plan.md`).
